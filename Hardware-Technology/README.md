# HWT101 - Module 1: Computer Hardware

**Components Inside System Unit:**
1. Motherboard - Heart of PC
2. CPU - Brain (Intel Core i5, i7)
3. RAM - Temporary memory (8GB, 16GB)
4. Storage - HDD vs SSD
5. PSU - Power Supply

**Practical Lab:** Open a dead PC, identify and label each part. Take photo and upload to assignment.

**Safety:** Wear anti-static wrist strap.

# Module 2: PC Assembly & Troubleshooting

**Steps to Assemble PC:**
1. Install CPU on Motherboard
2. Install RAM
3. Mount Motherboard in casing
4. Install HDD/SSD
5. Connect PSU cables
6. Connect front panel

**Common Faults:**
- No Display: Check RAM, VGA cable
- No Power: Check PSU, Power button
- Beep Sound: RAM error (continuous beep)
- Blue Screen: Driver or RAM fault

**Tool:** Use Hiren's Boot CD for diagnostics.

**Practical:** Disassemble and Reassemble Lab PC in 20 mins.
