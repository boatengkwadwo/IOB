# Module 2: Double Entry & Ledgers

**Double Entry Rule:** Every transaction has 2 sides - Debit and Credit.

Example 1:** Buy Computer GHS 3,000 cash.
- Dr Computer Equipment 3,000
- Cr Cash 3,000

**T-Account Format:**

Ledger Posting:** Post all journals to ledgers.

Task:** Journalize: 1. Paid rent GHS 500, 2. Sold goods GHS 1,200 cash.

# Module 3: Trial Balance & Financial Statements

**Trial Balance:** List of all ledger balances to check if Debit = Credit.

Format:
| Account | Dr (GHS) | Cr (GHS) |
| Cash | 7,000 | |
| Capital | | 10,000 |
| Computer | 3,000 | |
| **Total** | **10,000** | **10,000** |

If totals not equal, error exists.

**Financial Statements:**
1. Income Statement - Profit/Loss
2. Statement of Financial Position (Balance Sheet)
