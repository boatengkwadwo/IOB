# NET101 - Module 1: Introduction to Networking

**Learning Outcomes:** Define network, types, and devices.

**1. What is a Network?** Collection of devices sharing resources.

**2. Types:** LAN (Office), WAN (Internet), MAN (City)

**3. Network Devices:** Router, Switch, Hub, Access Point.

**4. OSI Model (MOST IMPORTANT):**
- Layer 7 Application - HTTP, Email
- Layer 4 Transport - TCP/UDP
- Layer 3 Network - IP Address & Routing
- Layer 1 Physical - Cables

- # Module 2: OSI Model & TCP/IP In Depth

**The 7 Layers Explained with Ghana Example:**
7. Application - You opening WhatsApp
6. Presentation - Encryption
5. Session - Login session
4. Transport - TCP ensures message arrives, UDP for fast video
3. Network - IP Address: 192.168.1.1 - Your digital house number
2. Data Link - MAC Address, Switch
1. Physical - Fiber cables from MTN, Cables in lab

**Encapsulation:** Data → Segment → Packet → Frame → Bits

**TCP/IP 4 Layers:** Application, Transport, Internet, Network Access
